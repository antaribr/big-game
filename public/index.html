📋 CSV Format
Export first to get the correct template. The CSV has these columns:
Category ID, Category Name, Task ID, Task Name, Evidence, Level, Comment

Points are automatic — Easy: 20, Medium: 30, Hard: 50, Rare: 70

To add tasks: Add new rows, keep same Category ID for existing category.
To edit tasks: Change values in the CSV and re-import.
To delete tasks: Remove the row and re-import.

⚠️ Import replaces ALL tasks — make sure your CSV has everything.

📖 Rules & Notes

📤 Submitting Tasks

  • Team leader submits to the designated advisor
  • Must provide: Task Category, Task Number, Evidence
  • All team members must be in the photo/video

🚫 Disqualification

  • 2+ members leave = disqualification
  • Cheating = point reduction or DQ
  • Disputes may result in DQ for both teams

🚶 Transportation

  • Walking ONLY — anything else = immediate DQ

⚠️ Important

  • Air strike/security incident = game stops immediately
  • Scores calculated at time of stop
  • Respect the environment — leave no trace
